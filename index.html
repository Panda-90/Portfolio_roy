Neurix AI

AI Chatbot with RAG Architecture

Neurix AI is a full-stack, Retrieval-Augmented Generation (RAG) powered coding assistant designed to help developers write, understand, and debug code more efficiently. By combining Large Language Models with a custom knowledge base, it delivers accurate, context-aware responses for code explanations, bug fixing, algorithm design, and software engineering best practices. Built with a scalable architecture, secure authentication, and an intuitive chat interface, Neurix AI enables developers to interact naturally with technical knowledge while improving productivity and problem-solving throughout the development lifecycle.

HealthInsight AI

Multi-Agent Healthcare Analytics Platform

HealthInsight AI is an Agentic AI-powered healthcare analytics platform designed to automate the analysis of healthcare datasets using a collaborative multi-agent architecture. The system consists of specialized AI agents responsible for data ingestion, statistical analysis, insight generation, recommendation creation, and response validation. Built with LangGraph orchestration and Large Language Models, the platform transforms complex healthcare data into accurate, explainable, and actionable insights. By combining traditional data analysis with intelligent reasoning, HealthInsight AI streamlines healthcare analytics while improving decision-making, scalability, and report generation.
